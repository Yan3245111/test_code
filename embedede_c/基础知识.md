# 中断流程
1.中断请求：外设/定时器触发中断信号
2.终端响应：cpu暂停当前程序，保存上下文
3.向量查询：通过中断向量表跳转到ISR（终端服务函数）
4.ISR执行：
5.退出中断

推挽：可输出高低信号，里面有2个晶体管，上管->拉高，下管->拉低
开漏：只能拉低/释放，需要外部上拉电阻，只有一个晶体管


# 接口对比区别
UART：2线 tx/rx   异步/同步 速率低  点对点    简单 距离比较远
I2C： 2线 SDA/SAL 同步      速率中  一主多从  半双工 上拉电阻
SPI:  4线 SCK/MISO/MOSI/CS 同步  速率高  一主多从  全双工 无应答  一般LCD/ADC/Flash用

I2C为开漏输出，只能拉低，无法主动拉高，上拉电阻提供高电平，速率越高电阻越小

# DMA原理与有点
DMA直接访问内存，无需CPU参与，外设与内存直接传输数据 一般用于串口 ADC LCD

# ADC和DAC
ADC: 模拟信号->数字信号  例如测量电压0-3.3v，转换成0-4095数字  范围都是自己设定的
DAC: 数字信号->模拟信号  例如数字2048，输出1.65v电压

# RS 232/ 485
232：点对点，电平+-12V，距离近15m，易受干扰
485：差分信号，半双工，一主多从，距离远1.2km，抗干扰强，工业常用 差分信号是两根线D+/D-上的电压差来传输信息，而不是用但单根线对地的绝对电压


# RTOS实时操作系统和裸机
裸机：单任务，轮询/中断，资源简单，适合小系统
RTOS：多任务并发，优先级调度，实时响应，任务通信/同步，内存管理，适合复杂实时系统。
# RTOS
抢占式优先级调度：高优先级任务立即抢占低优先级，同优先级任务平分时间片
同步：信号量，互斥锁，事件组，任务通知
通信：消息队列，共享内存
# 信号量
只有0和1两个值
用于任务同步，一个任务等待另一个任务或中断发出信号
可以跨任务释放
