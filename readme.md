网络通信分为：
应用层：用户交互层，http
传输层：应用层数据传输，tcp udp
网络层：数据解析，IP
数据链路层：链接硬件的层，例如网卡驱动
硬件层：数据的硬件层，光纤，路由

内存分区：
堆：new malloc对象
栈：局部变量
全局存储区：全局变量，statci extern
常量存储区：二进制代码


freeRTOS:
数字越大，优先级越高，内核消耗越大


系统中断：
数字越小，由下级越高


pack字节对齐
优点
1：节省空间
2：还有一些场景必须对齐，网络通信，文件格式
缺点：
1：有可能造成内存多次访问，访问速度变慢

spi:
全双工，4根线：MOSI MISO SCLK CS/SS(片选)
速度可以达到几M 几十M 距离短
布线复杂，没多一个从机就要多一个片选

iic:
半双工，2根线 SDA SCL
多主多从 速度几k到几M，布线简单

usart
全双工，4根线 RX TX GND CLK（同步才有，异步没有）
有起始位停止位 波特率
点对点，传输距离长

Queue
先进先出，比较简单
但是只能从队头插入，对尾删除
不能随机访问

zynq 7020简介
* PS 双核ARM 主频766MHz
* 8G eMMC 存储芯片 根文件系统相当于焊接在板子上的sd卡
* 32M QSPI Flash 启动硬盘 引导程序u-boot和linux-kernel系统内核
* 2个4G DDR ：系统运行的主力ram，arm运行系统是，先从flash读到ddr，然后cpu在ddr里运行代码，数据处理
* PS 33.3Mhz晶振
* PL 50Mhz 晶振
* 256k 片上ram 存储临时数据，断电数据小时

sram是ram的一种，静态随机存取存储器，不需要频繁刷新，随时读写用的
